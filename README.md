# Исправление GitHub Pages для Alert-alarm

1. Распакуйте ZIP. Загрузите содержимое этой папки в корень репозитория Alert-alarm с заменой index.html. Обязательно добавьте скрытую папку .github/workflows и папку scripts.
2. В репозитории откройте Settings → Pages → Build and deployment → Source и выберите GitHub Actions.
3. Откройте Actions → Update alerts and deploy → Run workflow. Если GitHub просит разрешить Actions — включите их для своего репозитория.
4. Дождитесь зелёной галочки. Откройте https://glebburunduchok.github.io/Alert-alarm/alerts-report.md — должен появиться текст с заголовком SITREP и временем отчёта.
5. На телефоне закройте старое окно ярлыка, откройте сайт заново, обновите страницу и нажмите «Увімкнути звук». Выберите регион, если он ещё не сохранён.

Компьютер можно выключить: обновление выполняет GitHub. Токен alerts.in.ua не нужен.

Проверка: источник отчёта загружается GitHub примерно раз в 5 минут; открытая страница проверяет файл каждую минуту. Это временный вариант с задержками, не мгновенная трансляция отбоя. GitHub может задерживать или пропускать запуски; в открытом репозитории после 60 дней без активности расписание отключается. Проверяйте Actions. Для постоянного оперативного обновления лучше отдельный серверный прокси.

При отсутствии отчёта, ошибке соединения или возрасте отчёта более 8 минут будильник звонит по времени без ожидания отбоя. Неизвестный статус не объявляется отбоем. При свежих данных выбранные уровни снова задерживают будильник. Уже начавшийся звонок не останавливается автоматически.

HTML по-прежнему требует открытую страницу, активный телефон и включённый звук во вкладке. Это исправление не добавляет системный будильник для заблокированного экрана.

Эта папка — готовый набор для GitHub Pages. Настройки вашего репозитория и публикация не меняются автоматически при скачивании ZIP.

Дополнения: ручная проверка с защитой от частых нажатий; отсчёт до следующей проверки; возраст отчёта; повторная проверка после возвращения в окно приложения. Неизвестный статус показывается отдельно от устаревшего. При смене региона во время запроса старый ответ не используется, следующий запрос запускается для нового региона. Прямой запрос из отдельного HTML остаётся раз в 3 минуты согласно ограничениям публичного источника.
