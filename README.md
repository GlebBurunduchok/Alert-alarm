# Тихий ранок — готово без ручной настройки API

Рабочий сайт: https://tykhyi-ranok-api.glebkrupnik.workers.dev/

Адрес API-сервера уже задан в приложении. Пользователи выбирают только область. Токен API остаётся секретом на сервере Cloudflare: не добавляйте его в GitHub, HTML или сообщения.

## Обновить GitHub Pages

В этом ZIP файлы уже лежат в нужной структуре. Распакуйте и загрузите ВСЁ содержимое прямо в корень Alert-alarm с заменой: index.html, sw.js, manifest.webmanifest, icon.svg, четыре PNG и папку .github/workflows. Не создавайте дополнительную папку вокруг этих файлов.

Settings → Pages → Source → GitHub Actions. Затем Actions → Deploy website → Run workflow. После успешного запуска обновите сайт на телефоне. Ввод адреса сервера и токена больше не нужен. Старые расписания получения текстовых отчётов можно отключить.

Ручной кнопки обновления тревог нет: проверка официального API выполняется автоматически раз в минуту. При отсутствии актуальных данных будильник звонит по времени. Иконка добавлена в шапку, вкладку браузера, манифест и apple-touch-icon для iPhone.

Для push: откройте настройки → Увімкнути push-сповіщення → разрешите уведомления → Надіслати тест. На iPhone открывайте сайт из значка на главном экране. Звук включается при первом взаимодействии, если браузер не разрешил его при загрузке. Для полноценного звонка по-прежнему нужны открытая страница и активный телефон.
